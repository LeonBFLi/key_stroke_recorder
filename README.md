# Windows 10 键盘鼠标录制、回放与红点监控工具

这是一个单文件入口、带中文图形界面的键盘鼠标宏、鼠标连点与红点监控工具。它使用全局输入监听，因此开始录制后可以切换到其他窗口继续工作；录制结果可保存为文件，并可按指定次数或持续循环回放。

> 请只在您拥有或获准操作的电脑和软件中使用本工具。回放会真实地发送按键、移动鼠标并点击，运行前请确认焦点位置。

## 功能

- 全局录制键盘按下/松开、鼠标移动和鼠标按下/松开，以及事件之间的高精度间隔，不要求工具窗口保持焦点。
- 按原始坐标和节奏回放鼠标轨迹与点击；回放采用单调时钟的绝对时间调度，减少长录制中的累计误差。
- 将录制保存为易于备份的 `.ksr.json` 文件。
- 加载已有录制并还原按键与原始节奏。
- 支持执行 1–9999 次，或一直循环到手动停止。
- 空闲时按全局 **F8** 可一键运行已加载或刚录制的鼠标键盘操作；任何功能运行时按 F8 仍会紧急停止所有任务。
- 支持 0.5–100 次/秒的鼠标左键连点，并可自定义全局启停热键。
- 支持最多 5 组相互独立的定时按键；每组都可现场录入一个键位并设置按键间隔，也可同时运行。
- 在同一窗口的“红点监控”标签页选择屏幕区域；发现红点时播放提示音，如果红点持续 N 秒未消失，则停止正在进行的键盘鼠标回放、保存监控区域截图，并关闭届时的前台窗口。

## 环境要求

- Windows 10（Windows 11 通常也可使用）。
- 若直接运行源码：Python 3.10 或更高版本。安装 Python 时请勾选 **Add Python to PATH**。

## 最简单的运行方法（源码）

1. 下载并解压本项目。
2. 双击 `run.bat`。首次启动会联网安装依赖，之后出现“键盘鼠标录制与回放工具”窗口。
3. 如果系统找不到 `py`，请重新安装 Python Launcher，或者在命令提示符中执行：

   ```bat
   python -m pip install -r requirements.txt
   python app.py
   ```

## 生成可直接运行的 EXE

1. 在联网的 Windows 10 电脑上安装 Python 3.10+。
2. 双击 `build.bat`，脚本会安装固定版本的依赖并调用 PyInstaller。
3. 构建成功后得到 `dist\KeyStrokeRecorder.exe`。该 EXE 可复制到另一台 Windows 10 电脑直接运行，无需安装 Python。

Windows 可能对未签名、自行构建的 EXE 显示 SmartScreen 提示。请核对文件确实由本项目源码构建后，再选择“更多信息 → 仍要运行”。发布给其他人时建议使用代码签名证书签名。

## 详细使用说明

### 1. 录制键盘和鼠标

1. 打开程序，点击 **开始录制**。F8 不再用于开始录制。
2. 切换到要操作的其他窗口，正常输入、移动鼠标并点击。工具在后台记录键盘按下/松开、鼠标移动轨迹、鼠标按下/松开及全部事件的时间间隔，不会抢占该窗口的焦点。
3. 完成后回到工具点击 **停止录制**；也可以在任意窗口按 **F8** 停止。
4. 状态区会显示录制的事件数量。录制过程中再次点击“开始录制”会清空上一段尚未保存的内容，所以请先保存需要保留的录制。

### 2. 保存录制

1. 停止录制后点击 **保存录制…**。
2. 选择目录和文件名。程序默认使用 `.ksr.json` 扩展名。
3. 此文件不含密码保护；如果录制中包含敏感文字，按键本身可能被还原，因此请妥善保管或及时删除。

### 3. 加载及回放

1. 点击 **选择录制文件…**，选择此前保存的 `.ksr.json` 文件。
2. 选择循环方式：
   - **指定次数**：输入 1–9999 的整数；
   - **一直循环，直到停止**：持续回放，不限制次数。
3. 先准备好目标窗口，再点击 **开始运行**，或在程序空闲时按全局 **F8**。程序会按照录制时的屏幕绝对坐标和节奏移动、点击鼠标并发送按键；录制中的第一段等待时间会保留，可用于切换窗口。为准确还原鼠标轨迹，建议录制与回放时保持相同的屏幕分辨率、缩放比例和窗口位置。
4. 点击界面的 **停止运行**，或者在任何窗口按 **F8**，即可请求停止。为防止按键状态错乱，程序会在当前等待点尽快结束。

### 4. 鼠标连点

1. 在“鼠标连点”区域填写每秒点击次数（0.5–100）。
2. 点击 **设置热键**，然后直接按下想使用的键盘按键、组合键或鼠标键，松开后程序会自动完成设置，无需输入按键名称。F8 固定保留为紧急停止键；鼠标左键用于执行连点，因此不能设为开关热键。
3. 点击 **开始连点** 后，把鼠标移到目标位置。再次按设置的热键、点击 **停止连点** 或按 **F8** 即可停止。
4. 连点使用单调时钟校正执行耗时，避免每次点击的耗时不断累积为频率偏差。

### 5. 红点监控

1. 打开“红点监控”标签页，点击 **选择监控区域**，拖动鼠标框选红点可能出现的位置；按 Esc 可取消框选。
2. 设置 **持续 N 秒后关闭窗口**。检测器除亮度、色差、饱和度和红团形状外，还会限制绿色/蓝色相对于红色的占比，以排除黄色、橙色等背景元素；默认值适合明显的纯红色小点，也可按画面微调。
3. 点击 **开始监控**。检测器会识别区域内任意位置的红点（包括移动中的红点），连续确认后立即发出提示音并开始倒计时。
4. 检测器会容忍截图中的短暂漏检；只有连续多帧未发现红点才判定其消失并取消关闭操作。若倒计时结束时仍存在，程序会先终止正在进行的键盘鼠标回放，将触发关闭时的监控区域保存为 `red_dot_detection_日期_时间.png` 到程序所在目录，再向当时的前台窗口发送关闭消息。
5. 点击 **停止监控** 或按全局 **F8** 可停止监控。关闭程序也会停止监控线程。

> “当前窗口”是倒计时结束那一刻 Windows 的前台窗口。为防止误关，请合理框选区域并先用较长的 N 值测试参数。

### 6. 定时按键

1. 在“定时按键”区域任选一行，点击 **录入按键**，然后直接按下需要自动发送的单个键位。
2. 填写两次按键之间的秒数（0.1–86400），点击该行的 **开始**。程序会先等待一个完整间隔，再发送第一次按键。
3. 五项可设置不同键位和间隔并同时运行；点击对应行的 **停止** 只停止该项，按 **F8** 则紧急停止全部任务。

## 注意事项与故障排除

- **权限要一致**：普通权限程序通常不能向“以管理员身份运行”的窗口发送按键。请让目标程序以普通权限运行，或以管理员身份启动本工具。
- **键盘布局**：建议录制和回放时使用相同的输入法、键盘布局及大小写状态，否则字符结果可能不同。
- **F8 的行为**：所有功能均空闲时，F8 会运行当前已加载或刚录制的鼠标键盘操作；如果尚无可运行的录制，则不会开始任务。有任一任务运行时，F8 会停止录制、回放、鼠标连点和红点监控。F8 不适合放进需要回放的宏中。
- **安全停止**：若目标应用响应异常，先按 F8；仍无响应可通过任务管理器结束 `KeyStrokeRecorder.exe`。
- **杀毒软件提示**：PyInstaller 单文件程序偶尔会被启发式扫描误报。可改为运行源码，或自行审阅源码后在本机重新构建。
- **无法监听**：检查杀毒/安全软件是否阻止全局键盘钩子，并确认本工具与目标程序权限级别一致。
- 本工具记录键盘事件、鼠标移动坐标和鼠标点击；不会记录窗口内容或屏幕画面。

## 开发与测试

```bat
py -m pip install -r requirements.txt
py -m unittest discover -s tests -v
```

项目入口是 `app.py`；文件格式目前为版本 2，包含键盘与鼠标事件相对于前一事件的延时及事件数据，并保持对版本 1 键盘录制文件的加载兼容。
