# Windows 10 键盘录制与回放工具

这是一个带中文图形界面的键盘宏工具。它使用全局键盘监听，因此开始录制后可以切换到其他窗口继续工作；录制结果可保存为文件，并可按指定次数或持续循环回放。

> 请只在您拥有或获准操作的电脑和软件中使用本工具。回放会真实地向当前活动窗口发送按键，运行前请确认焦点位置。

## 功能

- 全局录制按下、松开及按键间隔，不要求工具窗口保持焦点。
- 将录制保存为易于备份的 `.ksr.json` 文件。
- 加载已有录制并还原按键与原始节奏。
- 支持执行 1–9999 次，或一直循环到手动停止。
- 界面按钮和全局 **F8** 紧急停止键均可停止录制/回放。

## 环境要求

- Windows 10（Windows 11 通常也可使用）。
- 若直接运行源码：Python 3.10 或更高版本。安装 Python 时请勾选 **Add Python to PATH**。

## 最简单的运行方法（源码）

1. 下载并解压本项目。
2. 双击 `run.bat`。首次启动会联网安装依赖，之后出现“键盘录制与回放工具”窗口。
3. 如果系统找不到 `py`，请重新安装 Python Launcher，或者在命令提示符中执行：

   ```bat
   python -m pip install -r requirements.txt
   python app.py
   ```

## 生成可直接运行的 EXE

1. 在联网的 Windows 10 电脑上安装 Python 3.10+。
2. 双击 `build.bat`，脚本会安装固定版本的依赖并调用 PyInstaller。
3. 构建成功后得到 `dist\KeyStrokeRecorder.exe`。该 EXE 可复制到另一台 Windows 10 电脑直接运行，无需安装 Python。

Windows 可能对未签名、自行构建的 EXE 显示 SmartScreen 提示。请核对文件确实由本项目源码构建后，再选择“更多信息 → 仍要运行”。发布给其他人时建议使用代码签名证书签名。

## 详细使用说明

### 1. 录制按键

1. 打开程序，点击 **开始录制**。
2. 切换到要操作的其他窗口，正常输入或使用快捷键。工具在后台记录按键的按下、松开以及时间间隔，不会抢占该窗口的焦点。
3. 完成后回到工具点击 **停止录制**；也可以在任意窗口按 **F8** 停止。
4. 状态区会显示录制的事件数量。录制过程中再次点击“开始录制”会清空上一段尚未保存的内容，所以请先保存需要保留的录制。

### 2. 保存录制

1. 停止录制后点击 **保存录制…**。
2. 选择目录和文件名。程序默认使用 `.ksr.json` 扩展名。
3. 此文件不含密码保护；如果录制中包含敏感文字，按键本身可能被还原，因此请妥善保管或及时删除。

### 3. 加载及回放

1. 点击 **选择录制文件…**，选择此前保存的 `.ksr.json` 文件。
2. 选择循环方式：
   - **指定次数**：输入 1–9999 的整数；
   - **一直循环，直到停止**：持续回放，不限制次数。
3. 先准备好目标窗口，再点击 **开始运行**，随即切换并把焦点放在目标输入位置。录制中的第一段等待时间会保留，可用于切换窗口。
4. 点击界面的 **停止运行**，或者在任何窗口按 **F8**，即可请求停止。为防止按键状态错乱，程序会在当前等待点尽快结束。

## 注意事项与故障排除

- **权限要一致**：普通权限程序通常不能向“以管理员身份运行”的窗口发送按键。请让目标程序以普通权限运行，或以管理员身份启动本工具。
- **键盘布局**：建议录制和回放时使用相同的输入法、键盘布局及大小写状态，否则字符结果可能不同。
- **F8 的行为**：F8 被保留为紧急停止键，不适合放进需要回放的宏中。
- **安全停止**：若目标应用响应异常，先按 F8；仍无响应可通过任务管理器结束 `KeyStrokeRecorder.exe`。
- **杀毒软件提示**：PyInstaller 单文件程序偶尔会被启发式扫描误报。可改为运行源码，或自行审阅源码后在本机重新构建。
- **无法监听**：检查杀毒/安全软件是否阻止全局键盘钩子，并确认本工具与目标程序权限级别一致。
- 本工具只记录键盘事件，不记录鼠标、窗口内容或屏幕画面。

## 开发与测试

```bat
py -m pip install -r requirements.txt
py -m unittest discover -s tests -v
```

项目入口是 `app.py`；文件格式目前为版本 1，包含每个事件相对于前一事件的延时、动作、按键类型和值。
